Installer som en vanlig WordPress-plugin fra ZIP-filen til siste stabile versjon.

1. Last ned ZIP-en med knappen over, eller fra [GitHub-releasen](https://github.com/kimlukasmyrvold/wp-lucide-icons/releases).
2. I WordPress: **Plugins → Legg til ny → Last opp plugin**.
3. Velg ZIP-filen, installer og aktiver **WP Icons**.
4. Valgfritt: sett standarder og hvilke biblioteker som er på under **Utseende → WP Icons → Innstillinger**.

ZIP-en inneholder `vendor/` og `build/`. Uten autoloader viser pluginen en feilmelding i admin og lastes ikke.

Lite er samme plugin uten medfølgende ikonfiler, og vises som WP Icons Lite. Last den ned når den vanlige ZIP-en er for stor til å lastes opp.
