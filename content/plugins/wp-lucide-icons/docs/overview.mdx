WP Icons plasserer ikoner fra åtte åpne ikonbibliotek som inline SVG: Lucide, Material Symbols, Simple Icons, Phosphor, Tabler Icons, Heroicons, Ionicons og Octicons.

Pluginen heter WP Icons. Mappe og GitHub-repositorium er `wp-lucide-icons`. Til og med versjon 1.3.1 het den Lucide Icons og hadde bare Lucide.

Kim vedlikeholder pluginen. Benjamin Pedersen samarbeidet om redesignet i versjon 2.0.

Flatsome og Elementor er valgfrie. **WP Icons for Flatsome** er en egen plugin som legger WP Icons inn i Icon Box og Button.

Krever WordPress 6.6 eller nyere og PHP 8.1 eller nyere. GitHub-repositoriet er offentlig. Last ned ZIP-en fra GitHub Release `v2.0.0`.

Versjonene 1.0.2, 1.0.3 og 1.0.4 står i [endringsloggen](https://github.com/kimlukasmyrvold/wp-lucide-icons/blob/main/CHANGELOG.md), men er ikke publisert som GitHub Release.
