Ikonene settes inn i teksten du skriver. I Flatsome ligger **Insert icon** på verktøylinjen i teksteditoren. Klikk på et ikon som allerede står i setningen, så åpnes velgeren med det ikonet.

Samme knapp og samme klikk finnes i tekstmodulen i WPBakery, også når Woodmart bruker den, i Elementor sin visuelle teksteditor, i den klassiske editoren, og på avsnitt og overskrifter i Gutenberg.

Ett ikon for seg selv legges inn med blokken **Icon**, Elementor-widgeten **WP Icons** eller Flatsome-elementet **WP Icons**. Icon Box og Button i Flatsome dekkes av **WP Icons for Flatsome**.

Pluginen heter WP Icons. Mappe og GitHub-repositorium er `wp-lucide-icons`. Til og med versjon 1.3.1 het den Lucide Icons.

Kim vedlikeholder pluginen. Benjamin Pedersen samarbeidet om redesignet i versjon 2.0.

Krever WordPress 6.6 eller nyere og PHP 8.1 eller nyere. GitHub-repositoriet er offentlig. Last ned full ZIP eller Lite fra GitHub Release `v2.1.0`. Lite er samme plugin uten medfølgende ikonfiler.

Versjonene 1.0.2, 1.0.3 og 1.0.4 står i [endringsloggen](https://github.com/kimlukasmyrvold/wp-lucide-icons/blob/main/CHANGELOG.md), men er ikke publisert som GitHub Release.
