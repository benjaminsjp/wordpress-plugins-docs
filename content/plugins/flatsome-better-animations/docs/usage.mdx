Gå til **Innstillinger → Flatsome Motion**.

### UX Builder

På kolonne, rad, seksjon, tittel, tekst, knapp, bilde og flere andre elementer ligger gruppen **Motion**.

- **Rad / seksjon:** stagger-beholder. Sett **Stagger barn** til På og velg animasjon fritt på kolonne, tekst eller andre barn — de kommer inn etter hverandre. Valgfri animasjon på raden arves av kolonner som ikke har sin egen. Raden animeres ikke selv.
- **Kolonne / tekst / …:** velg animasjonen der den skal skje. Egen Delay-slider overstyrer auto-stagger.
- Tittel og tekst kan deles opp (tegn, ord eller linje) med egen tekststil.

### Flatsome data-animate

Overstyrer Flatsomes trege standard-tider og waypoint-offset for `[data-animate]`. Du kan justere transform-varighet, opacity-varighet, forflytningsdistanse og waypoint-offset (%).

### Reveal-klasser

Manuelle klasser under **Avansert → Klasse** virker fortsatt. Standardanimasjon, timing, easing og stagger justeres i innstillingene.

| Klasse | Effekt |
|--------|--------|
| `.reveal` | Standard fra innstillingene (fade + opp som utgangspunkt) |
| `.reveal.reveal--fade-up` | Fade + opp |
| `.reveal.reveal--down` / `--fade-down` | Fade + ned |
| `.reveal.reveal--left` / `--fade-left` | Fra venstre |
| `.reveal.reveal--right` / `--fade-right` | Fra høyre |
| `.reveal.reveal--fade` | Kun fade |
| `.reveal.reveal--zoom` / `--zoom-in` | Zoom inn |
| `.reveal.reveal--zoom-out` | Zoom ut |
| `.reveal.reveal--blur` | Uskarp |
| `.reveal.reveal--wipe` | Maske opp |
| `.reveal.reveal--wipe-l` | Maske fra venstre |
| `.reveal.reveal--tilt` | 3D-tilt |
| `.reveal.reveal--flip` | Snu |

**Stagger:** pakk elementer i `.reveal-stagger`.  
**Delay:** `data-reveal-delay="300"` (ms).  
**Tekst:** `.reveal-text` med `--rise`, `--fade`, `--blur` eller `--rot`, og `--tegn` / `--ord` / `--linje`.

Respekterer `prefers-reduced-motion` når innstillingen er på. Uten JavaScript vises innhold umiddelbart.
