Flatsome Motion gjør Flatsome-animasjoner raskere og mer moderne, og legger til et eget scroll-basert `.reveal`-system. I UX Builder velger du animasjon og stagger direkte på elementer, i gruppen **Motion**.

Tidligere navn: Flatsome Better Animations. Slug og innstillingsnøkkel er uendret (`flatsome-better-animations` / `fba_settings`).

Flatsome-temaet trengs for `data-animate`-overstyringen og UX Builder-feltene. Manuelle `.reveal`-klasser fungerer også uten.

GitHub-repositoriet er offentlig. Last ned ZIP-en fra GitHub Release `v2.0.1`.
