Flere og bedre inngangsanimasjoner for Flatsome. Elementer glir, fader og zoomer inn når leseren scroller til dem. Alt styres fra UX Builder og ett admin-panel, uten egen CSS.

Tidligere navn: Flatsome Better Animations. Slug og innstillingsnøkkel er uendret (`flatsome-better-animations` / `fba_settings`).

### Hva pluginet gjør

- **12 ferdige inngangsanimasjoner** som kan velges per element i UX Builder.
- **Tekstanimasjon** som viser overskrifter og tekst bit for bit (per tegn, ord eller linje).
- **Stagger:** la barn i en rad eller seksjon komme inn etter hverandre med økende forsinkelse.
- **Raskere Flatsome-animasjoner:** kan erstatte Flatsomes egne `data-animate`-animasjoner med lettere varianter.
- **Tilgjengelighet:** respekterer «reduser bevegelse» og laster scriptet forsinket.

Flatsome-temaet trengs for `data-animate`-overstyringen og UX Builder-feltene. Manuelle `.reveal`-klasser fungerer også uten.

GitHub-repositoriet er offentlig. Last ned ZIP-en fra GitHub Release `v2.0.2`.
