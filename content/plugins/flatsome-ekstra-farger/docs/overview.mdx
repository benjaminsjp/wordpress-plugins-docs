Flatsome Ekstra Farger utvider Flatsomes innebygde fargesystem med muligheten til å opprette egne farger og knappestiler.

Egne farger kan brukes på samme måte som Flatsomes standardfarger. De er tilgjengelige i UX Builder og kan justeres under **Theme Options → Style → Colors**. Dette gjør det enklere å holde fargebruken konsekvent på tvers av nettstedet.

Du kan også opprette egne knappestiler med tilpassede bakgrunns- og tekstfarger. Disse blir tilgjengelige under **Color** på knappeelementer i UX Builder.

Pluginet er tilgjengelig fra et offentlig GitHub-repositorium. Du kan laste det ned som en ZIP-fil fra releasen `v1.0.0`.
