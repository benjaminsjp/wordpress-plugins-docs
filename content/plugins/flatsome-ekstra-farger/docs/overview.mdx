Pluginen utvider Flatsome med egne farger og knappestiler. Fargene blir CSS-variabler, vises under **Style → Colors** i Customizer og som ekstra prøver i UX Builder. Knappestiler velges under **Color** på knappeelementer.

GitHub-repositoriet er offentlig. Last ned ZIP-en fra GitHub Release `v1.0.0`.
