Gå til **Utseende → Ekstra farger** (krever `edit_theme_options`).

### Farger

Legg til rader med **navn** og **farge** (hex, for eksempel `#1a2b3c`). Navnet brukes som etikett i UX Builder og Customizer. Ved lagring får fargen en unik ID og CSS-variabelen `var(--fs-color-{id})`.

Verdier kan finjusteres i Customizer; de lagres som theme mod.

### Knappestiler

Hver stil har **navn**, **bakgrunn** og **tekstfarge**. Klassen blir `fef-btn-{id}` (for eksempel `fef-btn-merke`). Stilene dukker opp i **Color**-listen for knapper i UX Builder, sammen med Flatsome sine standardvalg.

Outline-, link- og underline-varianter støttes.

ID-ene `primary`, `secondary`, `success`, `alert` og `white` er reservert og kan ikke brukes som egne farger eller knapper.
