Pluginen fyller Gravity Forms-felter fra WooCommerce-produktet brukeren ser på (produktside, gjeldende produkt i loop og lignende). Felter kan låses som skrivebeskyttet, og avkrysningsbokser/flervalg kan forhåndsvelges.

Krever WooCommerce og Gravity Forms. GitHub-repositoriet er offentlig. Last ned ZIP-en fra GitHub Release `v1.1.8`.
