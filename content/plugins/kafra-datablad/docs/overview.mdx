Pluginen håndterer PDF-datablad knyttet til WooCommerce-produkter. Last opp dokumenter, koble dem til produkter, og vis dem på produktsider eller i et søkbart dokumentarkiv.

Krever WooCommerce. GitHub-repositoriet er offentlig: [`kafra-datablad`](https://github.com/bli-synlig-plugins/kafra-datablad). Last ned ZIP-en fra GitHub Release `v1.2.2`.

Se også [Kafra Auto Skjema](/plugins/kafra-auto-skjema) og [Kafra Produktkatalog](/plugins/kafra-produktkatalog).
