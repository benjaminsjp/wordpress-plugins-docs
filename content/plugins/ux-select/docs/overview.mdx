Pluginen gir to Flatsome UX Builder-elementer: **Select** og **Select-innhold**. Select viser en valgliste (for eksempel fylker). Select-innhold er en container som viser eller skjuler innhold ut fra valget, og kan ligge et annet sted på siden enn selve listen.

Sett og valg opprettes under **Innstillinger → UX Select**. Ett panel kan vises for flere valg i samme sett, slik at samme innhold kan gjelde både Østfold og Akershus.

Krever Flatsome for UX Builder-elementene. Uten Flatsome vises en admin-advarsel; shortcodene rendres likevel.

GitHub-repositoriet er offentlig. Last ned ZIP-en fra GitHub Release `v1.0.0`.
