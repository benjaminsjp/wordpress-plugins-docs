Installer som en vanlig WordPress-plugin fra ZIP-filen til siste stabile versjon.

1. Aktiver **Flatsome** først (UX Builder).
2. Last ned ZIP-en med knappen over, eller fra [GitHub-releasen](https://github.com/bli-synlig-plugins/ux-select/releases).
3. I WordPress: **Plugins → Legg til ny → Last opp plugin**.
4. Velg ZIP-filen, installer og aktiver **UX Select**.
5. Gå til **Innstillinger → UX Select** og opprett minst ett sett med valg.
6. I UX Builder: legg til **Select** og **Select-innhold** fra kategorien **Content**.
