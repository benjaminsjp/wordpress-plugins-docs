Pluginen legger til Flatsome UX Builder-elementer som filtrerer blogginnlegg med ACF-taksonomier. Filtreringen kjører med AJAX, og Polylang brukes til å synkronisere taksonomier mellom språk.

Den vises som **Blogg filter (ACF + Polylang)** i WordPress. Uten Polylang eller ACF lastes ikke pluginen, og wp-admin viser en feilmelding.

GitHub-repositoriet er offentlig. Last ned ZIP-en fra GitHub Release `v1.0.5` (filen `blogg-post-plugin-for-flatsome-1.0.5.zip`) når releasen er publisert.
