Pluginen gir et videogalleri med horisontal slider, egne undersider per video, og støtte for YouTube og Vimeo. Videoer kan kobles til prosjekter, sider eller innlegg.

Shortcodes og admin fungerer uten Flatsome. UX Builder-elementet **Videogalleri** (under **Content**) krever Flatsome.

GitHub-repositoriet er offentlig. Last ned ZIP-en fra GitHub Release `v1.1.1`.
