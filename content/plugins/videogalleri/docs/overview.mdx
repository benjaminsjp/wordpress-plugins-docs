Pluginen gir et videogalleri med horisontal slider, en frittstående videospiller, egne undersider per video, og støtte for YouTube, Vimeo og Kontainer. Videoer kan kobles til prosjekter, sider eller innlegg.

Shortcodes og admin fungerer uten Flatsome. UX Builder-elementene **Videogalleri** og **Videospiller** (under **Content**) krever Flatsome.

GitHub-repositoriet er offentlig. Last ned ZIP-en fra GitHub Release `v1.3.0`.
