I UX Builder finner du utvidede **Icon Box** (featured box), **Button** og **Menu link**-elementer med WP Icons-støtte.

- Egendefinert option type `wpicons` som åpner WP Icons-velgeren
- Velg bibliotek, ikon og variant (for eksempel Phosphor-vekt eller Heroicons-stil)
- Størrelse, farge og stroke overføres fra velgeren
- På Menu link: posisjon (venstre/høyre), align (start/center/end) og gap mellom ikon og tekst
- Frontend-CSS for riktig visning av både stroke- og fill-ikoner i Flatsome-komponenter

Bygg eller rediger en side med UX Builder, legg til Icon Box, Button eller Menu, velg **WP Icons** som ikonkilde, og åpne velgeren. På Menu ligger innstillingene på hvert **Menu link**. Eksisterende innhold med det gamle formatet `library/name` vises fortsatt.
