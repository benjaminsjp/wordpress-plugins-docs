I UX Builder finner du utvidede **Icon Box** (featured box) og **Button**-elementer med WP Icons-støtte.

- Egendefinert option type `wpicons` med ikonvelger
- Frontend-CSS for riktig visning av ikoner i Flatsome-komponenter

Bygg eller rediger en side med UX Builder, legg til Icon Box eller Button, og velg ikon fra WP Icons i stedet for bilde eller Flatsome-ikon.
