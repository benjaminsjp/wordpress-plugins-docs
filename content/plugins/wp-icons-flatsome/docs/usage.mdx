I UX Builder finner du utvidede **Icon Box** (featured box) og **Button**-elementer med WP Icons-støtte.

- Egendefinert option type `wpicons` som åpner WP Icons-velgeren
- Velg bibliotek, ikon og variant (for eksempel Phosphor-vekt eller Heroicons-stil)
- Størrelse, farge og stroke overføres fra velgeren
- Frontend-CSS for riktig visning av både stroke- og fill-ikoner i Flatsome-komponenter

Bygg eller rediger en side med UX Builder, legg til Icon Box eller Button, velg **WP Icons** som ikonkilde, og åpne velgeren. Eksisterende innhold med det gamle formatet `library/name` vises fortsatt.
