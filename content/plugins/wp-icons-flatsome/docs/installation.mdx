Installer som en vanlig WordPress-plugin fra ZIP-filen til siste stabile versjon.

1. Aktiver **WP Icons** (`wp-lucide-icons`) først.
2. Last ned ZIP-en med knappen over, eller fra [GitHub-releasen](https://github.com/bli-synlig-plugins/wp-icons-flatsome/releases).
3. I WordPress: **Plugins → Legg til ny → Last opp plugin**.
4. Velg ZIP-filen, installer og aktiver **WP Icons for Flatsome**.
