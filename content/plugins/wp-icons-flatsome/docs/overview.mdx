Pluginen lar deg velge ikoner fra **WP Icons** (Lucide m.m.) i Flatsome UX Builder — i stedet for innebygd bildeopplasting eller Flatsome sitt ikonsett.

Krever Flatsome (UX Builder) og at **WP Icons** (`wp-lucide-icons`) er aktiv. Uten WP Icons vises en admin-feilmelding. Uten Flatsome vises advarsel; integrasjonen aktiveres når Flatsome er i bruk.

GitHub-repositoriet er offentlig: [`wp-icons-flatsome`](https://github.com/bli-synlig-plugins/wp-icons-flatsome). Last ned ZIP-en fra GitHub Release `v1.0.0`.
