Pluginen lar deg velge ikoner fra **WP Icons** i Flatsome UX Builder — i stedet for innebygd bildeopplasting eller Flatsome sitt ikonsett.

Krever Flatsome (UX Builder) og at **WP Icons 2.0+** er aktiv (mappenavn `wp-lucide-icons` eller `wp-icons`). Uten WP Icons vises en admin-feilmelding. Uten Flatsome vises advarsel; integrasjonen aktiveres når Flatsome er i bruk.

GitHub-repositoriet er offentlig: [`wp-icons-flatsome`](https://github.com/bli-synlig-plugins/wp-icons-flatsome). Last ned ZIP-en fra GitHub Release `v1.1.0`.
