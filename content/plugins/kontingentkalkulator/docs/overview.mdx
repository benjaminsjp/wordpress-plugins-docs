Pluginen gir Flatsome UX Builder-elementer som regner ut reell fagforeningskontingent ut fra månedslønn eller timelønn. Resultatet trekker fra skattefradrag og eventuelle aktive forsikringer.

Satser, tekster og forsikringer settes globalt i wp-admin. Farger og standardverdier settes på elementet i UX Builder.

GitHub-repositoriet er offentlig. Last ned ZIP-en fra GitHub Release `v1.0.0`.
